---
title: "Convert Document"
openapi: "POST /api/v1/convert"
---

Upload a document and get it back in another format, saved as a new asset.
Use it when the file isn't in Dreep yet, or when you want the converted file
stored on its own. For documents you've already uploaded, you can also
[convert them by URL](/transformations/documents).

## Word to PDF

```bash
curl -X POST "https://api.dreep.cloud/api/v1/convert" \
  -H "Authorization: Bearer drp_live_xxxxx" \
  -F "file=@contract.docx" \
  -F "format=pdf"
```

```json
{
  "asset": {
    "id": "5c1d8a72-3f0e-4b8d-9a61-2e7b4c9d0f13",
    "folderId": "a41f0c2e-6b7d-4e8a-9f3c-1d2e5b6a7c8d",
    "filename": "contract.pdf",
    "format": "pdf",
    "mimetype": "application/pdf",
    "sizeBytes": 104719,
    "status": "ready",
    "url": "https://api.dreep.cloud/api/v1/fetch/5c1d8a72-3f0e-4b8d-9a61-2e7b4c9d0f13.pdf"
  }
}
```

## Saving to a folder

With no folder given, the result is saved to the project's default folder.
Name one with `folder` (a path, created on demand), `folderId` (a UUID) or
`key` (a full path that also names the file):

```bash
curl -X POST "https://api.dreep.cloud/api/v1/convert" \
  -H "Authorization: Bearer drp_live_xxxxx" \
  -F "file=@report.xlsx" \
  -F "format=pdf" \
  -F "folder=reports/2026"
```

See [Folders & Paths](/guides/folders-and-paths).

## What converts to what

| Upload | `format` |
| :--- | :--- |
| Word: `doc`, `docx`, `odt`, `rtf` | `pdf`, `docx`, `odt`, `rtf` |
| Excel: `xls`, `xlsx`, `ods`, `csv` | `pdf`, `xlsx`, `ods`, `csv` |
| PowerPoint: `ppt`, `pptx`, `odp` | `pdf`, `pptx`, `odp` |
| PDF | `docx`, `png`, `jpeg` |

Anything else returns `400` with the formats that file can convert to.
Converting a spreadsheet to `csv` exports its first sheet.

To render one page of a PDF as an image, pass `page`:

```bash
curl -X POST "https://api.dreep.cloud/api/v1/convert" \
  -H "Authorization: Bearer drp_live_xxxxx" \
  -F "file=@brochure.pdf" \
  -F "format=png" \
  -F "page=2"
```

## Long conversions

The request waits for the result, up to two minutes. Most documents take a
second or two and return `201`.

A very long document returns `202` with `status: "processing"`. The asset
already exists, and its `url` answers `202` until the conversion finishes,
then serves the file. Poll the URL, as with
[video transformations](/transformations/videos).

## Billing and limits

Each conversion counts toward your plan's monthly document conversions:
**Free** 100, **Starter** 2,000, **Pro** 10,000. If the same document was
already converted the same way through its fetch URL, that result is reused
for free.

| | Free | Starter and Pro |
| :--- | :--- | :--- |
| Largest document | 10 MB | 100 MB |
| PDF output | First 5 pages | All pages |
| PDF to Word | Not included | Included |
| PDF page images | Pages 1 to 5 | Any page |

Going over a limit returns `402` with `code: "LIMIT_EXCEEDED"` and
`featureKey: "document_conversions_monthly"`. The saved result also counts
toward your storage, so a full storage quota returns `402` too. A conversion
only counts once the result is stored, so a failed request costs nothing.
