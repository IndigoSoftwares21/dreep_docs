Upload a video asset and optionally apply processing options (trimming, FPS adjustment, container re-encoding).

**Supported Video Inputs**: MP4 (`.mp4`), MOV (`.mov`), WebM (`.webm`).

<Note>
**Allowed Conversion Target Formats**: `mp4`, `webm`, `mov`, `hls` (`.m3u8`), `gif` (animated clip). Requesting static image target formats (e.g. `jpeg` or `webp`) on video uploads is blocked.
</Note>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.dreep.cloud/api/v1/upload \
  --header 'Authorization: Bearer drp_live_xxxxx' \
  --header 'Content-Type: multipart/form-data' \
  --form file='@clip.mp4' \
  --form folderId=fol_987654321 \
  --form format=mp4 \
  --form trimStart=0 \
  --form trimEnd=15 \
  --form fps=30
```

</RequestExample>
