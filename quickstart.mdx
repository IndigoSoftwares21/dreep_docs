  clients with typed transforms — `pip install dreep`.
</Note>

<Note>
  Working with an AI agent? The [MCP server](/mcp/introduction) gives Claude, Cursor, VS
  Code and others these endpoints as tools — `npx -y dreep-mcp`.
</Note>

## Authentication

All API requests require an API key to be passed via the `Authorization` header as a Bearer token.

```bash
Authorization: Bearer drp_live_xxxxx
```

## Upload and Process Media

You can upload and transform media in a single request. 

### Example: Uploading an Image

```bash
curl -X POST "https://api.dreep.cloud/api/v1/upload" \
  -H "Authorization: Bearer drp_live_xxxxx" \
  -F "file=@hero.jpg"
```

The response will contain the CDN URL for your newly processed asset.
